# 88Slots Prototype

Демо-прототип онлайн-казино в стиле 88Slots.

## Запуск

Требуется Node.js 18+ (рекомендуется актуальная LTS).

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно:
http://localhost:5173

## Что есть

- Lobby 88Slots
- Категории: Все / Бар / Клуб / Казино / Косморынок
- Поиск по играм
- Карточки игр
- Одна демо-игра 5×3
- Виртуальный баланс 1000 €
- Ставка 0.20–20.00 €
- Spin
- Auto
- Max Bet
- Wild
- Scatter
- Free Spins
- 5 paylines
- Адаптивная верстка
- Только виртуальные ставки, без реальных денег

## Структура

- `index.html` — точка входа
- `src/main.js` — UI и игровая логика
- `src/style.css` — интерфейс 88Slots
- `package.json` — Vite scripts

Это учебный/демонстрационный прототип, а не готовая система азартных игр на реальные деньги.
