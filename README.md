# 88Slots Prototype

Демо-прототип онлайн-казино в стиле 88Slots. Только виртуальные ставки, без реальных денег.

## Запуск

Требуется Node.js 18+ (рекомендуется актуальная LTS).

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно http://localhost:5173

| Игра | Категория | Механика |
| --- | --- | --- |
| Book of Gold | Казино | 10 линий, Free Spins с раскрывающимся символом |
| Candy Cascade | Клуб | Кластеры 6×5, Tumble, растущий множитель в бонусе |
| Olympus Storm | Казино | 243 ways, Wild-множители ×2/×3/×5 в бонусе |

| Lucky Piggy | Бар | 10 линий, липкие Wild в бонусе |
| Hound House | Клуб | 243 ways, липкие Wild с множителями |
| Cosmic Gems | Косморынок | 10 линий в обе стороны, расширяющийся Wild + Re-spin |
| Nova Reels | Косморынок | Динамические барабаны 2–6 символов, до 7776 ways |
| Dragon Fortune | Казино | 1024 ways (5×4), липкие Wild в бонусе |
| Wild West Bounty | Клуб | 10 линий, Wild фиксируется и даёт Re-spin |
| Fruit Frenzy | Бар | 10 линий, каскады с множителями ×1…×8 |
| Royal Vegas 777 | Казино | Классика 3×3, Wild с множителем ×2/×3 |
| Alien Hive | Косморынок | 1024 ways, каскады с множителями |

Общее для всех игр: баланс 1000 € (хранится в браузере), ставка 0.20–20.00 €, Spin, Auto, Max Bet,
Wild, Scatter, Free Spins (проигрываются автоматически), подсветка выигрышных комбинаций,
оверлеи Big/Mega/Epic Win, таблица выплат и правила (кнопка ⓘ), звук (🔊), адаптивная вёрстка.
Максимальный выигрыш за раунд ограничен 5000× ставки.

## Структура

- `index.html` — точка входа
- `src/engine.js` — математика слотов (без DOM): линии, ways, кластеры, tumble, бонусы
- `src/games.js` — конфиги 13 игр: символы, веса, таблицы выплат, правила
- `src/rtp.js` — калибровочные коэффициенты выплат (генерируется симулятором)
- `src/main.js` — интерфейс: лобби, каталог, игровой экран, анимации
- `src/style.css` — стили
- `tools/sim.mjs` — Монте-Карло симуляция и калибровка RTP

## Графика

Символы — 3D-иконки [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (MIT, лицензия в `public/sym/LICENSE.txt`), буквы и самоцветы нарисованы на CSS. У каждой игры своя сцена, рамка и палитра.

## RTP

Таблицы выплат откалиброваны так, чтобы расчётный RTP был около 95%:

```bash
npm run sim          # перекалибровать все игры и обновить src/rtp.js
npm run sim:check    # только отчёт (RTP, частота выигрышей, частота Free Spins, макс. выигрыш)
node tools/sim.mjs gold bass --spins=1000000   # выбранные игры, свой размер выборки
```

Проверка на 1.5 млн раундов на игру даёт RTP в диапазоне 94–98%; разброс — из-за редких крупных бонусных выигрышей.

Это учебный/демонстрационный прототип, а не готовая система азартных игр на реальные деньги.
